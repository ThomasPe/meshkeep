Rules this copy has to keep (Microsoft Store Policies 7.20, checked 2026-11-20):

- **Search terms (10.1.3):** at most seven terms or phrases, and no titles of other

  in the same change.

## English

**Name:** Meshkeep

**Short description (100 chars):** Your 3D print models, organized like a photo library. Local and fast, no account, no cloud.

**Description:**

Meshkeep is a library manager for 3D printing models. Point it at the folders where your
STL, OBJ and 3MF files already live and it turns them into a browsable, searchable
library with rendered previews, tags, favorites and collections. Your files stay exactly
where they are, nothing is moved without asking, and the metadata you add lives in a
small, readable `project.yaml` next to them. There is no account, no telemetry and no
advertising; nothing leaves your computer unless you turn on one of the optional features
described below.

- Rendered previews for STL, OBJ and 3MF, generated in the background
- Slicer project files (PrusaSlicer, Bambu Studio, OrcaSlicer) recognized with their embedded preview
- Instant search over titles, creators, tags, descriptions and file names
- Tags, creator, license, source link, printing notes per project
- Favorites, recent additions, manual collections and saved searches
- Import zips from Printables, MakerWorld or Thingiverse straight into new projects
- Keep a download packed: models can stay inside their zip and are still previewed and searched
- Inbox for loose downloads, promote them to projects when you are ready
- Network shares and external drives: offline folders keep their entries
- Deletions go to the Recycle Bin, renames rename the folder on disk
- English and German, light and dark theme

Optional AI assistance (generative AI). Meshkeep can ask a generative AI model to suggest
a title, description, tags, creator and license for a project. This stays off until you
enter your own API key for a provider of your choice (Anthropic by default, or any service
with a compatible endpoint, including one on your own computer). A suggestion is requested
only when you click the button for a project; that project's preview image, file names and
sizes, README and license text and the metadata already recorded are then sent to the
provider. Model files are never sent. Suggestions are generated by an AI model and can be
wrong: you tick what you want, and nothing is written before you apply it. To report an
inappropriate suggestion, use Settings → Feedback or meshkeep.app/support.

Optional: load model pages. Turned on in the settings, Meshkeep can open the web page
stored as a project's source link, when you ask for it, and offer the creator, license,
tags and cover picture found there.

Optional: connection for AI agents. With the local MCP server turned on, an AI program on
the same computer can search the library and, if you allow it, fill in metadata and import
downloads. It is off by default, reachable from this computer only and protected by a
token.

Made for people who print a lot and have folders full of models they can no longer find.

## Partner Center answers

**Generative AI.** Declare that the product contains live generative AI content wherever
the submission asks for it, and repeat it in the notes for certification (below). What the
answer rests on: text suggestions for one project's metadata, produced by a third-party
model the user configures with their own key, shown in a dialog and written only after the
user applies them.

**Notes for certification** (English, paste as is):

> Meshkeep is a packaged desktop app (runFullTrust). To test it, start the app, choose
> "Add folder" and pick any folder that contains STL, OBJ or 3MF files. No account is
> needed and the app has no updater of its own.
>
> Three optional features are off by default:
>
> 1. AI assistance (live generative AI, policy 11.16). It needs the user's own API key
>    from a third-party provider (Settings → AI assistance) and cannot be exercised
>    without one. Its output is a set of suggested metadata fields for one project (title,
>    description, tags, creator, license), shown in a dialog; nothing is saved until the
>    user applies it. Users report inappropriate output through Settings → Feedback →
>    "Report a bug or idea" or at https://meshkeep.app/support/.
> 2. Load model pages (Settings → Network). On request, the app fetches the web page
>    stored as a project's source link and offers the metadata found there.
> 3. MCP server (Settings → AI agents). A local endpoint on 127.0.0.1, protected by a
>    token, for AI programs on the same computer. The package registers the app execution
>    alias meshkeep.exe so that such a program can start the app's stdio bridge
>    ("meshkeep.exe --mcp"); started that way the app shows no window.
